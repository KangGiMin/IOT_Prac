# 디지털 PNG 작업대와 계측 오버레이

## 좌표 원본

`src/config/digitalPins.ts`가 브레드보드 홀·바인딩 포스트·계측기 단자·LCD·조작 영역·LED 위치를 백분율로 정의합니다. 제공된 EIC-108 PNG의 4구역·63열 신호 홀과 전원 레일의 실제 홀 중심·그룹 사이 간격에 맞춰 연결점을 보정했습니다. 사진의 전원 레일은 각각 50홀이며, 기존 파일에서 사용하는 1–63 레일 단자 ID는 동일 bus의 실제 홀에 대응하는 별칭으로 유지합니다. 4개 바인딩 포스트는 서로 독립이며 전원 레일에 자동 연결하지 않습니다. 각 5홀 열, 중앙 홈, 4개 구역, 상/중/하 전원 레일의 bus는 분리됩니다. 평상시에는 단자 원을 표시하지 않고 사진의 구멍에서 직접 배선합니다. PNG를 교체하면 좌표를 다시 보정해야 합니다.

PNG 파일 내부 투명 여백은 포함하고 `object-fit:contain` 레터박스는 제외합니다. 헤더의 핀 좌표 디버그를 사용해 보정합니다. 개별 PNG가 없는 현재 저장소에서는 플레이스홀더가 표시됩니다.

## IC 모델과 삽입

팔레트에 7400 / 7402 / 7406 / 7408 / 7411 / 7486을 각각 표시하며 모두 `ic-14pin.png`를 사용합니다. 드래그 시 모델 메타데이터를 함께 전달하고, 이미지 위에 모델명을 표시합니다. 우측 패널에서도 전원 OFF에서 모델을 변경할 수 있습니다.

IC를 브레드보드 중앙 영역으로 드래그한 뒤 놓으면 가까운 홈과 7개 연속 열에 맞춥니다. 1–7번은 F행, 14–8번은 E행에 꽂히고 `insertion` 메타데이터를 통해 자동으로 해당 홀과 같은 Net에 병합됩니다. 별도 가짜 전선을 만들지 않습니다. 동일한 구역의 점유된 7열에는 중복 삽입하지 않습니다. 보드 밖으로 옮기면 분리되며, 브레드보드 삭제 시 삽입 정보도 정리합니다. 장착 크기에 맞춰 이미지를 축소하고 단자 오버레이는 실제 홀 월드 좌표에 일치시킵니다.

`src/config/ttlModels.ts`가 사용자 지정 실제 핀맵의 단일 원본입니다.

| 모델 | 기능      | 입력 → 출력                           |
| ---- | --------- | ------------------------------------- |
| 7400 | NAND      | 1,2→3 / 4,5→6 / 9,10→8 / 12,13→11     |
| 7402 | NOR       | 2,3→1 / 5,6→4 / 8,9→10 / 11,12→13     |
| 7406 | NOT       | 1→2 / 3→4 / 5→6 / 9→8 / 11→10 / 13→12 |
| 7408 | AND       | 1,2→3 / 4,5→6 / 9,10→8 / 12,13→11     |
| 7411 | 3입력 AND | 1,2,13→12 / 3,4,5→6 / 9,10,11→8       |
| 7486 | XOR       | 1,2→3 / 4,5→6 / 9,10→8 / 12,13→11     |

14=VCC, 7=GND를 공통 적용합니다. 각 모델의 출력 핀을 논리 계산·출력 충돌 검사·단자 역할 표시가 함께 읽으므로 7402와 7411에 NAND 핀맵을 잘못 적용하지 않습니다. 미급전·부동·미정 논리는 임의로 0/1로 채우지 않습니다.

7406 기본 NOT 모드는 요청에 따른 학습용 능동 HIGH 근사입니다. 실제 7406은 오픈컬렉터이므로 우측 오픈컬렉터 옵션을 켜면 HIGH에서 출력을 해제하고 LOW에서만 싱크합니다. 외부 풀업이 없으면 부동, 330Ω 풀업이 있으면 HIGH가 됩니다. 오픈컬렉터 출력끼리는 풀업 Net 공유를 허용하며 일반 능동 출력의 직접 충돌은 보호 정지합니다. [TI 제조사 7406 데이터시트](https://www.ti.com/lit/ds/symlink/sn7406.pdf)

## 전원과 파형

GP-4303TP: CH1 +/−(설정 전압), CH2 +/−(학습용 고정 5V), 5V +/−, 독립 GND 접지를 제공합니다. CH1/CH2 LCD에 설정 전압과 해석 전류를 표시하며 기본은 5.0V / 0.00A입니다. OUTPUT은 메인 전원과 별도이며 OFF면 공급 전위를 제거합니다. 오류 시 모든 동작 출력을 차단하고 C.C / OVERLOAD 위치의 붉은 LED를 켭니다.

전류는 부하 가지 전류와 IC가 HIGH 출력으로 공급하는 전류를 합산한 교육용 DC 값입니다. IC 자체 소비 전류, 실제 TTL 전류 제한과 전원장치의 전류 제한 곡선은 계산하지 않습니다. 전원들은 공통 이상 DC 기준을 사용하므로 부유·절연 출력의 직렬 적층이나 병렬 전원의 전류 분배는 지원하지 않습니다. GND 접지는 출력 −와 자동 병합하지 않습니다.

DS5152C: 화면 사각형에 HTML canvas를 배치합니다. CH1 노란색, CH2 파란색으로 연결 노드를 직접 샘플링하고 실제 상태 변화에 따라 계단형 디지털 파형을 기록합니다. LOW는 0V, HIGH는 5V로 표시하며 부동/미정은 선을 끊습니다. 500ms/div, 5초 이력 창입니다. REF를 연결하면 해당 노드를 기준으로 측정하고 미연결 REF는 시뮬레이터 공통 0V를 사용합니다. RUN/STOP을 누르면 기록을 재개/정지하며 STOP에서는 기존 파형을 고정합니다. 출력이 안정된 DC일 때는 평평한 선이 정상이며 임의의 주기 파형을 생성하지 않습니다. 오실로스코프는 입력을 구동하지 않습니다.

## 다른 부품과 배선

LED는 A(긴 다리 +) / K(짧은 다리 −)를 표시하며 정상 순방향 전류가 흐를 때 머리 부분을 붉게 발광합니다. 330Ω 저항의 양 끝은 별도 Net이고, 슬라이드 스위치는 공통핀을 좌/우 접점에 실제 병합하며 레버 위치도 표시합니다.

헤더의 전선 종류에서 점퍼선/악어클립을 선택한 뒤 배선합니다. 점퍼선은 사각형 핀 헤드나 아래로 돌출된 끝단 없이, 선 자체가 단자·브레드보드 구멍 중심에서 둥글게 끝나도록 표시합니다. 투명 연결 영역의 윗변과 실제 구멍 중심 사이 차이도 보정하므로 확대해도 끝이 중심에 유지됩니다. 악어클립은 클립 형상을 표시하고 개별 전선에 종류를 저장합니다. 시퀀스 Y단자 배선도 유지합니다.

## 검증

`npm.cmd test`, `npm.cmd run build`를 사용합니다. 6종 모든 게이트의 전 입력 조합과 실제 핀맵, 7406 풀업·부동·싱크·공유 Net, 7411의 13번 입력, 7402 출력 충돌, 14개 다리의 보드 삽입, 공급 전류·OUTPUT OFF·쇼트 차단, 프로브 0/5V와 부동 신호, 팔레트·RUN/STOP UI를 검사합니다.

현재 브라우저 호스트가 연결되지 않아 실제 PNG와의 시각 정합, 호버/드래그 및 canvas 동작을 브라우저에서 직접 확인하지 못했습니다. 최종 PNG 설치 후 디버그 모드에서 좌표를 보정하세요.
