# 계측·논리 학습 센터

상단 도구 모음의 **계측·논리 학습 센터**로 이동합니다. 라이트·다크·시스템 테마를 따르며 좁은 화면에서는 조작 패널을 세로로 배치하고 넓은 표·차트 내부만 가로로 스크롤합니다. 세 학습 탭은 회로 실습과 함께 사용할 수 있습니다.

## 오실로스코프 시작

1. 디지털 NAND 예제를 불러오고 메인 전원을 켭니다. CH1은 입력 A, CH2는 출력 Y, GND REF는 전원 0V에 연결되어 있습니다.
2. 채널 소스를 **회로 프로브**로 두고 스위치를 조작합니다. LOW=0V, HIGH=5V이며 미연결·미정 신호는 끊긴 선입니다. REF 미연결을 0V로 가정하지 않습니다.
3. 아날로그 실습은 **정현파 예제**를 누릅니다. 발생기 1kHz·4Vpp·0V 오프셋에서 약 1ms 주기, 2V 피크, 1.414Vrms를 확인합니다. 발생기는 회로와 독립적이며 회로 단자를 구동하지 않습니다.
4. VOLTS/DIV와 수직 위치, TIME/DIV와 수평 위치를 바꿔 눈금의 의미를 확인합니다. 사진의 전압 다이얼 대상은 CH1/CH2 버튼으로 선택합니다. 다이얼은 키보드 방향키·Home·End로도 조작합니다.
5. AUTO는 신호 크기·주기에 맞게 축을 조정합니다. AUTO 트리거는 조건이 없어도 갱신하고 NORMAL은 조건을 기다립니다. SINGLE은 새 조건을 한 번 취득한 뒤 멈추며 FORCE는 조건과 무관하게 한 번 취득합니다. STOP은 기존 데이터를 고정합니다.

### 조작과 측정

| 영역 | 구현된 기능 |
| --- | --- |
| 채널 | 켜기/끄기, 소스 선택, DC/AC/GND, 반전, 프로브 실제/메뉴 1×·10×, 전압축·수직 위치 |
| 발생기 | 정현파·구형파·삼각파·톱니파·DC, 0.1Hz~10kHz, 0~20Vpp, DC 오프셋, 위상, 구형파 듀티 |
| 시간·트리거 | 10µs/div~10s/div, 수평 위치, CH1/CH2, 상승·하강 에지, 레벨, AUTO/NORMAL/SINGLE, FORCE, 50% |
| 취득·표시 | 1,024점, SAMPLE, 4/16회 AVERAGE, 구간 최솟값·최댓값 PEAK 표시, Y–T, XY, FFT |
| 연산·비교 | CH1+CH2, CH1−CH2, REF 기준 파형 저장·회색 점선 비교 |
| 자동 측정 | 최솟값·최댓값·Vpp·평균·RMS·주파수·주기·듀티·HIGH/LOW 폭·10~90% 상승/하강 시간 |
| 커서·파일 | X1/X2 슬라이더·파형 위 드래그, Y1/Y2, Δt·1/Δt·ΔV, 취득 CSV·화면 PNG |

AC는 취득 구간의 평균을 제거하는 근사입니다. FFT는 평균 제거·Hann 윈도·1,024점 FFT의 피크 전압 스펙트럼이며 하드웨어 분석기 보정이나 정밀 전력 측정용이 아닙니다. XY는 CH1을 가로, CH2를 세로 축에 둡니다. REF 버튼의 기준 파형과 배선용 **GND REF 단자**는 서로 다른 기능입니다.

실제/메뉴 프로브 배율을 다르게 설정하면 진폭 오차와 경고가 나타납니다. DC·미연결·불충분한 에지에서 주파수나 펄스 폭을 임의로 만들지 않고 `—`로 표시합니다. 주기당 20점 미만이면 표본 부족 경고가 나타나므로 시간축을 조절합니다. 화면의 샘플 속도는 시간축에 따라 달라집니다. 실물 PNG의 150MHz·500MSa/s 표기는 브라우저 성능을 뜻하지 않습니다.

회로 프로브는 해석 상태가 바뀔 때 기록하고 최근 이력을 최대 4,000개 변화점으로 제한합니다. 빠른 아날로그 파형은 내장 발생기의 이상적 모델을 샘플링합니다. 회로 해석을 SPICE 아날로그 해석으로 확장하거나 실물 USB/SCPI·프로브 보정·교정·전체 펌웨어 메뉴를 모사하지 않습니다.

계측 설정은 Undo/Redo와 회로 JSON에 포함합니다. 취득 기록·REF 샘플은 메모리에만 유지하며 새로고침 시 사라집니다. 사진의 MEASURE/CURSOR/STORAGE/UTILITY 등은 해당 확장 조작과 사용 안내를 엽니다.

## 카르노 맵

- 2·3·4변수를 선택하고 각 칸을 `0 → 1 → X`로 편집합니다. 행과 열은 Gray 순서이며 인접 칸에서 한 변수만 달라집니다.
- SOP에서는 1을, POS에서는 0을 묶습니다. X는 필요한 경우만 포함합니다. X만 있는 묶음은 만들지 않습니다.
- **묶음 선택 모드**에서 칸들을 고르고 **선택 칸 묶기**를 누릅니다. 1·2·4·8·16칸 직사각형, 좌우·상하 순환을 허용하고 대각선·L자·반대 값 포함을 거부합니다. 겹치는 묶음을 허용합니다.
- **내 묶음 검증**으로 필요한 값이 모두 덮였는지 확인합니다. **자동 간소화 보기**는 주항을 구한 뒤 정확한 커버 탐색으로 항 수, 이어 리터럴 수가 최소인 한 가지 식을 제시합니다. 유일한 정답을 뜻하지 않습니다.
- 네 모서리 예제 `m0,m2,m8,m10`은 순환하는 한 묶음이며 `¬B·¬D`로 줄어듭니다. 상수 함수·Don’t care·7게이트 예제와 접이식 설명도 제공합니다.

## 타임 차트

1. 게이트·구간 수·구간 시간·시간 단위를 선택합니다. **모든 입력 조합 채우기**는 변수 순서대로 이진 조합을 생성합니다.
2. 입력 칸을 클릭해 0·1·X를 바꿉니다. 한 구간마다 진리표로 출력 값을 정한 뒤 **내 출력**에 기록합니다.
3. 정답을 가리고 연습한 뒤 **내 타임 차트 채점**을 누릅니다. 각 구간 중앙 시점에서 전파 지연을 적용한 출력과 비교합니다. 시간축 위의 수직 경계와 지연된 에지 위치를 함께 확인합니다.
4. **7가지 게이트 출력 동시에 비교**로 같은 A/B 입력에 대한 AND·OR·NOT·NAND·NOR·XOR·XNOR 출력을 봅니다. NOT은 A만 사용합니다.
5. 사용자 논리식은 A~D, 상수 0/1, `!` 또는 `~` 또는 `¬`, `&` 또는 `*` 또는 `·`, `^` 또는 `⊕`, `|` 또는 `+`, 괄호를 지원합니다. 우선순위는 NOT → AND → XOR → OR입니다. 예: `!(A & B) | C`. 문자열을 코드로 실행하지 않습니다.
6. SVG로 파형을, CSV로 구간 중앙의 시간·입력·정답·내 출력을 저장합니다.

여기서 X는 미정 신호입니다. `0 AND X = 0`, `1 OR X = 1`처럼 확정 가능한 결과만 계산하며, 카르노 맵의 Don’t care와 다릅니다. 전파 지연 이전의 출력은 X이고 지연은 각 출력에 동일하게 적용합니다. 순차 회로·개별 게이트별 지연·글리치의 물리적 해석은 포함하지 않습니다.

## 소스와 검증

계측 모델·검증은 `src/features/scope/`, 학습 UI·카르노 간소화·안전한 논리식 파서는 `src/features/learning/`에 있습니다. 사진 조작 좌표는 `src/config/digitalPins.ts`의 백분율을 수정합니다.

단위 검사는 파형·트리거·AC·배율·FFT·측정, 2/3변수 전체 진리 함수와 4변수 표본 간소화, 순환 묶음, 논리식·X·전파 지연을 검증합니다. 브라우저 검사는 프로브·발생기 측정, SINGLE/STOP·저장, 실제 사진 조작, 커서·REF, 카르노 수동 묶기, 타임 차트 채점, 테마·좁은 화면을 검사합니다.
