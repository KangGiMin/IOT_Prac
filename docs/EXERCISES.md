## 배선과 검증

도면 위의 번호를 누르면 해당 버튼/릴레이의 c·a·b 위치와 쉬운 동작 설명이 표시됩니다. `접점 이름 표시`로 표시를 끄고, 확대 막대로 작은 기호를 살펴봅니다. 3점 전환접점은 움직이는 선의 시작점이 c, 평소 닿은 쪽이 b, 떨어진 쪽이 a입니다. 2점 기호의 c*/a*/b*는 한 쌍을 읽기 위한 설명 기준이며, 그림만으로 실제 소켓의 COM 방향을 확정하지 않습니다. 원본에서 기호가 생략된 곳은 ?로 구분합니다.

오른쪽의 **한 가닥씩 따라 하는 배선**은 내부 C/J 코드 대신 `3번 PB1 버튼 · 아래쪽 점` 같은 이름을 사용합니다. `이 접점 도면에서 보기`로 양쪽 접점을 강조하고 `이 선 연결하기`로 한 가닥을 잇습니다. 같은 물리 단자와 선의 분기점을 묶어, 한 점을 자기 자신에 연결하거나 동일 선을 반복하라는 안내를 만들지 않습니다. 직접 단자 선택과 기존 해설 배선 불러오기도 유지합니다.

선택한 도면 제목 옆의 **완성된 작업대 보기**는 현재 도면의 부품과 배선을 별도 작업대에 엽니다. 전원을 켜고 PB를 눌러 릴레이, 램프, 타이머, 부저와 모터의 상태를 확인합니다. 목록에서 배선을 선택하면 선과 양쪽 단자가 강조됩니다. 04·10번의 완성 작업대는 동작 가능한 수정안으로 열립니다. 직접 연결한 배선은 창을 닫은 뒤 이어서 실습할 수 있습니다.

회로는 AND/OR를 직렬/병렬로 펼친 명시적인 netlist로 계산합니다. 원본에 없는 등가 모델 접점에는 도면 위치를 임의로 붙이지 않습니다. 수식과 실제 소켓 핀 번호표는 접이식 설명으로 제공합니다.

접점 블록의 1/2는 논리 접점의 양 끝이며 실물 소켓 핀 번호가 아닙니다. 소켓 대응은 코일 13−/14+, COM 9~12, a 5~8, b 1~4입니다. 이 화면은 접점 단위 배선 연습으로, 기존 PNG 작업대와 별도 모델입니다. 실제 PNG 작업대에는 도면 배선을 자동 이식하지 않습니다.

연습 전원 ON 후 PB를 누르고 놓으면 코일·접점·램프·타이머가 갱신됩니다. ON 지연은 급전 뒤 설정 시간이 지나면 접점이 바뀝니다. OFF 지연은 급전 즉시 접점이 바뀌고, 급전이 끊긴 뒤 설정 시간이 지나면 원위치로 돌아옵니다. Union-Find로 실제 학습자 배선의 노드를 병합하며 부하는 노드를 병합하지 않습니다. 전원 +/− 직접 연결 시 보호 정지합니다. 반복 상태가 안정되지 않으면 접점 경합으로 표시합니다.

자동 테스트는 화면을 바꾸지 않는 복사본에서 단독 입력·해제·시간 경과·입력 순서 반전을 실행하고, 학습자 netlist의 코일·부하·모터 결과를 등록된 해석 모델과 단계별 비교합니다. 모델과의 일치는 실물 기계적 지연·접점 바운스까지 보장하는 판정이 아닙니다.

## 원본에서 확정할 수 없는 내용

- 사용자 선택에 따라 04·10번을 원본 그대로 보존하고 별도 수정안을 제공합니다. 04번 PB3의 생략된 접점 기호는 NO로 가정했음을 표시합니다.
- 02번 모터 공통선, 05번 운전 허가, 23번 모터 권선/방향 내부 결선은 원본에 필요한 정보가 모두 있지 않습니다. 모터는 두 단자에 걸린 전압의 극성을 판독하는 교육용 등가 모델이며, 원본의 모든 권선/기계 동작을 복원한 모델은 아닙니다.
- 14번 표시 접점은 원본에 둘 다 R2-a로 되어 있으므로 L1/L2 동시 점등을 유지합니다.
- 24번 동시 입력의 물리적 우선순위를 임의로 정하지 않습니다.
- 25번 교재 도면에는 지연 시간이 없어 T1과 T2를 각각 1초로 설정했습니다. 26번은 도면에 적힌 0.5초를 적용했습니다. 26번 점선은 R1 접점을 통과한 전원을 T1, T2, LAMP1, LAMP2 가지로 나눕니다.

회로 제목과 분류는 도면 접점의 연결 구조를 읽은 해석이며 원본에 인쇄된 공식 제목이 아닙니다. 각 문제의 주의 문구와 급전 조건을 원본과 함께 확인합니다.

도면별 상대 좌표는 `drawingContacts.ts`, 쉬운 배선 안내와 단자 대응은 `easyGuide.ts`, 그림 표시는 `DrawingLesson.tsx`에서 조정합니다. 같은 폴더의 `model.ts`, `solver.ts`, `ExercisesPage.tsx`가 회로와 화면을 담당합니다. 접점·타이머 개념은 [OMRON 기술 안내](https://www.ia.omron.com/support/guide/19/further_information.html)를 참고했습니다. 이미지 정리와 보관 경로는 [정리 기록](DRAWING_CLEANUP.md)에 있습니다.
