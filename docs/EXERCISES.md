## 배선과 검증

원본 옆의 연결 안내를 한 단계씩 따라가거나, 접점 블록의 단자 두 개를 선택해 연결합니다. AND는 직렬, OR는 병렬로 펼쳐 전원·접점·분기점·부하·0V 복귀의 명시적인 netlist를 만듭니다. J는 도면의 공통 분기점입니다. 각 접점의 소유 PB/릴레이와 NO/NC를 표시합니다.

접점 블록의 1/2는 논리 접점의 양 끝이며 실물 소켓 핀 번호가 아닙니다. 소켓 대응은 코일 13−/14+, COM 9~12, a 5~8, b 1~4입니다. 이 화면은 접점 단위 배선 연습으로, 기존 PNG 작업대와 별도 모델입니다. 실제 PNG 작업대에는 도면 배선을 자동 이식하지 않습니다.

연습 전원 ON 후 PB를 누르고 놓으면 코일·접점·램프·타이머가 갱신됩니다. 타이머는 연속 급전 시간을 적산하고 전원이 끊기면 초기화합니다. Union-Find로 실제 학습자 배선의 노드를 병합하며 부하는 노드를 병합하지 않습니다. 전원 +/− 직접 연결 시 보호 정지합니다. 반복 상태가 안정되지 않으면 접점 경합으로 표시합니다.

자동 테스트는 화면을 바꾸지 않는 복사본에서 단독 입력·해제·시간 경과·입력 순서 반전을 실행하고, 학습자 netlist의 코일·부하·모터 결과를 등록된 해석 모델과 단계별 비교합니다. 모델과의 일치는 실물 기계적 지연·접점 바운스까지 보장하는 판정이 아닙니다.

## 원본에서 확정할 수 없는 내용

- 사용자 선택에 따라 04·10번을 원본 그대로 보존하고 별도 수정안을 제공합니다. 04번 PB3의 생략된 접점 기호는 NO로 가정했음을 표시합니다.
- 02번 모터 공통선, 05번 운전 허가, 23번 모터 권선/방향 내부 결선은 원본에 필요한 정보가 모두 있지 않습니다. 모터는 두 단자에 걸린 전압의 극성을 판독하는 교육용 등가 모델이며, 원본의 모든 권선/기계 동작을 복원한 모델은 아닙니다.
- 14번 표시 접점은 원본에 둘 다 R2-a로 되어 있으므로 L1/L2 동시 점등을 유지합니다.
- 24번 동시 입력의 물리적 우선순위를 임의로 정하지 않습니다.

회로 제목과 분류는 도면 접점의 연결 구조를 읽은 해석이며 원본에 인쇄된 공식 제목이 아닙니다. 각 문제의 주의 문구와 급전 조건을 원본과 함께 확인합니다.
