# 시퀀스 PNG 모듈과 좌표 보정

시퀀스 모드의 이미지 단자·버튼·바늘·발광 영역과 판넬 레일·릴레이 장착 위치는 `src/config/sequencePins.ts`에서 관리합니다. 좌표는 0–100%이며 최종 누끼 PNG로 미세 보정해야 합니다. `assets.ts`에는 파일명·크기·설명만 유지합니다.

- 판넬: 부품 드래그를 놓으면 가장 가까운 가로 레일에 중심을 정렬하고 판넬 좌우 범위로 제한합니다. 디버그 모드에서는 레일 가이드가 표시됩니다.
- 램프: 24V급 폐회로에서 중심의 radial-gradient 발광을 켭니다. 전원 ON만으로 켜지지 않습니다.
- PB: 기본 동작은 디텐트입니다. 한 번 누르면 ON 상태가 유지되고 다시 누르면 OFF로 돌아옵니다. 우측 ‘버튼 동작’에서 모멘터리를 선택하면 포인터나 키를 누르는 동안만 동작합니다. 불러온 회로는 저장된 버튼 동작을 따르며, 버튼 동작을 기록하지 않은 이전 파일은 모멘터리로 열립니다.
- 릴레이: 라이브러리의 투명한 ‘릴레이 소켓’을 단자 모듈인 ‘릴레이 본체’ 중앙으로 드래그합니다. 본체 하나에 소켓 하나만 장착됩니다. 소켓을 장착하지 않으면 코일과 접점이 도통하지 않습니다. 장착 상태에서 여자되면 LED와 짧은 틱 소리가 발생합니다. 전원 OFF에서 소켓을 밖으로 드래그해 분리합니다. 본체 이동 시 장착 소켓도 함께 이동합니다. 내부 ID와 파일명은 기존 회로와의 호환성을 위해 유지합니다(`relay-socket`: 화면의 본체, `relay-body`: 화면의 소켓).
- 타이머: 다이얼을 원형 드래그하거나 방향키·Home·End로 0–10초를 설정합니다. 전원은 후면 소켓 스트립 2(−)/7(+)에 연결합니다. A On-Delay 모드로 COM 1/8, NO 3/6, NC 4/5를 전환합니다. RUN은 계시 중 점멸하고 OUT은 시간 경과 후 켜집니다. 실제 급전이 끊기거나 메인 전원을 끄면 초기화됩니다. 앱은 40ms 주기로 시간축을 갱신하며 순수 엔진은 `nowMs`를 주입해 결정적으로 검증할 수 있습니다.
- 배선: 헤더 ‘배선 모드 ON’에서 사진 속 실제 나사를 클릭하거나 드래그해 연결합니다. 푸시버튼·램프·릴레이의 연결점은 제공된 PNG의 나사 중심에 맞췄으며, 평상시에는 투명한 입력 영역만 두고 별도의 초록색 원은 표시하지 않습니다. PNG 드라이버를 브라우저 커서 크기로 축소해 사용하며 이미지가 없으면 십자 커서로 대체합니다. SVG 베지어 케이블 양 끝에는 Y단자가 표시됩니다. 전선은 사진 위에 보이되, 클릭 판정에서는 모든 단자와 조작 영역을 제외해 분기 배선이나 스위치 조작을 가리지 않습니다. 전선 우클릭으로 삭제합니다. 정상 전원 ON 중에는 배선을 변경할 수 없고 보호 정지 중에는 오류 전선을 삭제할 수 있습니다.

타이머 정면 사진에는 후면 단자가 없으므로 아래쪽에 번호가 있는 나사와 ‘후면 소켓’ 표시를 둡니다. 판넬의 가상 실습 전원도 +24V/0V 나사 단자로 구분합니다. 이는 원래 사진 속 나사와 구분되는 실습용 오버레이입니다. 0초 설정은 사용자가 요청한 학습 범위의 이상 모델입니다.

AT8N A모드 접점과 POWER/RUN/OUT 동작은 [Autonics 제조사 매뉴얼](https://pim.galco.com/Manufacturer/Autonics/TechDocument/Instruction%20Manual/at8n_en_ma_181004_w_im.pdf)을 참조했습니다. 단자 좌표와 소켓의 화면상 배열은 실제 사용 PNG에 맞춰 보정하세요.

개별 PNG 7개를 `public/assets/` 바로 아래에 설치합니다. 현재 제공된 시퀀스 PNG는 원본을 유지하고 영문 파일명으로 복사해 연결했습니다. 디지털 PNG는 추가 설치할 수 있으며 이미지가 없으면 플레이스홀더를 표시합니다. PNG 보정 절차는 `public/assets/README.md`를 참고하세요.

검증: `npm.cmd test`, `npm.cmd run test:e2e`(빌드 포함). 시간 경과/0초/급전 단절, 릴레이 장착 조건, 레일 스냅·장착 유일성·동반 이동·분리와 기존 DC/TTL 회귀 검사를 포함합니다. 실제 브라우저에서는 사진의 나사 중심을 직접 클릭·드래그하는 배선, 연결된 나사에서의 분기, 후면 소켓 급전과 전선 아래 조작 영역 접근을 검사합니다. 스피커 청음은 별도 수동 확인 항목입니다.
