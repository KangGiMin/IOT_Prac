# 시퀀스 PNG 모듈과 좌표 보정

시퀀스 모드의 이미지 단자·버튼·바늘·발광 영역과 판넬 레일·릴레이 장착 위치는 `src/config/sequencePins.ts`에서 관리합니다. 좌표는 0–100%이며 최종 누끼 PNG로 미세 보정해야 합니다. `assets.ts`에는 파일명·크기·설명만 유지합니다.

- 판넬: 부품 드래그를 놓으면 가장 가까운 가로 레일에 중심을 정렬하고 판넬 좌우 범위로 제한합니다. 디버그 모드에서는 레일 가이드가 표시됩니다.
- 램프: 24V급 폐회로에서 중심의 radial-gradient 발광을 켭니다. 전원 ON만으로 켜지지 않습니다.
- PB: 우측 ‘버튼 동작’에서 모멘터리/디텐트를 선택합니다. 디텐트는 클릭마다 유지/해제하며 모멘터리는 포인터·키를 놓으면 해제합니다.
- 릴레이: 본체를 소켓 오른쪽의 RELAY 장착 영역 중앙으로 드래그합니다. 한 소켓에 본체 하나만 장착됩니다. 빈 소켓은 코일과 접점이 도통하지 않습니다. 장착 상태에서 여자되면 본체 LED와 짧은 틱 소리가 발생합니다. 전원 OFF에서 본체를 밖으로 드래그해 분리합니다. 소켓 이동 시 장착 본체도 함께 이동합니다.
- 타이머: 다이얼을 원형 드래그하거나 방향키·Home·End로 0–10초를 설정합니다. 전원은 후면 소켓 스트립 2(−)/7(+)에 연결합니다. A On-Delay 모드로 COM 1/8, NO 3/6, NC 4/5를 전환합니다. RUN은 계시 중 점멸하고 OUT은 시간 경과 후 켜집니다. 실제 급전이 끊기거나 메인 전원을 끄면 초기화됩니다. 앱은 40ms 주기로 시간축을 갱신하며 순수 엔진은 `nowMs`를 주입해 결정적으로 검증할 수 있습니다.
- 배선: 헤더 ‘배선 모드 ON’에서 단자를 연결합니다. PNG 드라이버를 브라우저 커서 크기로 축소해 사용하며 이미지가 없으면 십자 커서로 대체합니다. SVG 베지어 케이블 양 끝에는 Y단자가 표시됩니다. 연결 시 단자 나사가 회전하고 전선 우클릭으로 삭제합니다. 정상 전원 ON 중에는 배선을 변경할 수 없고 보호 정지 중에는 오류 전선을 삭제할 수 있습니다.

타이머 정면 사진에는 후면 단자가 없으므로 아래쪽에 ‘후면 소켓’ 스트립으로 구분해 표시합니다. 이는 사진의 전면 부품으로 오인하지 않도록 한 실습용 오버레이입니다. 0초 설정은 사용자가 요청한 학습 범위의 이상 모델입니다.

AT8N A모드 접점과 POWER/RUN/OUT 동작은 [Autonics 제조사 매뉴얼](https://pim.galco.com/Manufacturer/Autonics/TechDocument/Instruction%20Manual/at8n_en_ma_181004_w_im.pdf)을 참조했습니다. 단자 좌표와 소켓의 화면상 배열은 실제 사용 PNG에 맞춰 보정하세요.

개별 PNG 7개를 `public/assets/` 바로 아래에 설치합니다. 현재 제공된 시퀀스 PNG는 원본을 유지하고 영문 파일명으로 복사해 연결했습니다. 디지털 PNG는 추가 설치할 수 있으며 이미지가 없으면 플레이스홀더를 표시합니다. PNG 보정 절차는 `public/assets/README.md`를 참고하세요.

검증: `npm.cmd test`, `npm.cmd run build`. 시간 경과/0초/급전 단절, 릴레이 장착 조건, 레일 스냅·장착 유일성·동반 이동·분리와 기존 DC/TTL 회귀 검사를 포함합니다. 브라우저 호스트가 없어 실제 드래그·점멸 캡처와 청음 검증은 수행하지 못했습니다.
